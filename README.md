# AeroWeather Frontend

This is a premium, glassmorphic weather prediction interface built with React, TypeScript, and Tailwind CSS.

## Features
- **Intelligent Prediction**: Connects to a FastAPI machine learning backend.
- **Glassmorphic UI**: Modern aesthetic with backdrop blurs and subtle gradients.
- **Responsive Design**: Fully optimized for mobile and desktop.


## How to Run

1. **Prerequisites**: Ensure you have Node.js installed.
2. **Setup**:
   ```bash
   npm install
   ```
3. **Execution**:
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:3000`.
